# Project 4 - Decision Tree Classification

## Aim

To implement the Decision Tree Classification algorithm on the Wine Quality dataset.

## Dataset

Wine Quality Dataset (`WineQT.csv`)

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Tasks Performed

* Loaded and explored the Wine Quality dataset
* Performed data analysis and visualization
* Split the dataset into training and testing sets
* Implemented Decision Tree Classification using Entropy
* Evaluated the model using accuracy, precision, recall, and F1-score
* Generated classification report and confusion matrix
* Visualized the Decision Tree
* Performed ROC-AUC analysis and hyperparameter tuning
