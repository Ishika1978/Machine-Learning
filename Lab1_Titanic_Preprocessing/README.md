# Project 1 - Titanic Data Preprocessing


## Aim

To study and apply data preprocessing techniques on the Titanic dataset.


## Dataset

Titanic Dataset



## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn


## Tasks Performed

- Imported the required libraries
- Loaded the Titanic dataset
- Explored the dataset using `head()`, `tail()`, `shape()`, `info()`, and `describe()`
- Identified and handled missing values
- Encoded categorical features (`Sex` and `Embarked`)
- Removed unnecessary columns and duplicate records
- Visualized the data using box plots, histograms, count plots, scatter plots, and a correlation heatmap
- Applied feature scaling using `StandardScaler`
