# Lab 7 – Naïve Bayes Classification

## Aim

To implement the Naïve Bayes Classification algorithm on the Raisin Dataset.

## Dataset

Raisin Dataset

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Tasks Performed

- Loaded and explored the Raisin Dataset
- Performed data analysis and visualization
- Checked missing values and duplicate records
- Analysed class distribution
- Performed univariate analysis using histograms and boxplots
- Performed correlation and bivariate analysis
- Generated scatter plots and class-wise KDE plots
- Encoded the target classes using LabelEncoder
- Split the dataset into training and testing sets using stratified sampling
- Implemented Gaussian Naïve Bayes Classification
- Evaluated the model using accuracy, precision, recall, and F1-score
- Generated a confusion matrix
- Compared training and testing accuracy
- Performed hyperparameter tuning using `var_smoothing`
- Predicted the class of a new raisin sample
