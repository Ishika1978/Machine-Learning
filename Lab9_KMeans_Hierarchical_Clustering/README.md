# Lab 9 – K-Means and Hierarchical Clustering

## Aim

To implement K-Means and Hierarchical Clustering on the Wholesale Customers dataset, compare the clustering results, and identify customer segments.

## Dataset

Wholesale Customers Dataset (`Wholesale customers data.csv`)

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy

## Tasks Performed

- Loaded and explored the dataset
- Checked missing values and duplicate records
- Selected and scaled customer spending features
- Used the Elbow Method to select the number of clusters
- Calculated Silhouette Scores
- Implemented K-Means Clustering
- Implemented Agglomerative Hierarchical Clustering
- Plotted full and truncated dendrograms
- Visualized customer clusters using PCA
- Compared cluster sizes and spending profiles
- Analysed channel composition within K-Means clusters
- Compared clustering algorithms using evaluation metrics
- Generated business insights from cluster profiles
