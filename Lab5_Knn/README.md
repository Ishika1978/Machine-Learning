# Lab 5 – K-Nearest Neighbors (KNN) Classification

This lab implements the **K-Nearest Neighbors (KNN)** classification algorithm on the **Diabetes Dataset**.

### Objectives
- Perform Exploratory Data Analysis (EDA) on the Diabetes Dataset
- Handle invalid zero values and missing data
- Split the dataset into training and testing sets
- Standardize features using `StandardScaler`
- Train a KNN classification model
- Evaluate the model using Accuracy, Precision, Recall, F1-score and Confusion Matrix
- Analyze different values of K
- Perform cross-validation and hyperparameter tuning using `GridSearchCV`

### Dataset
The **Diabetes Dataset** contains **768 records and 9 columns**, including 8 input features and `Outcome` as the target variable.

### Result
The initial KNN model with **K = 5** achieved a **test accuracy of 75.32%**.

**Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | Jupyter Notebook**
